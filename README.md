## 💻 Sobre o Projeto

Este repositório contém o código-fonte do portfólio pessoal de **Carlos Fernandes Fidalgo** (`@carlos17041976`). O projeto foi concebido com uma estética **Cyberpunk / Tech Futurista**, combinando efeitos de *Glassmorphism*, paleta de cores Neon sobre fundo escuro (`#070913`), animações fluidas e elementos interativos para apresentar minha trajetória acadêmica, habilidades técnicas e projetos de software.

---

## ✨ Funcionalidades e Destaques Visuais

- **🎨 Identidade Visual Cyberpunk & Neon:** Paleta baseada em tons escuros profundos combinados com variáveis CSS vibrantes (`--neon-cyan`, `--neon-purple`, `--neon-green` e `--neon-pink`) e sobreposição de grade tecnológica (`cyber-grid-overlay`).
- **🌌 Fundo Interativo (`<canvas>`):** Estrutura preparada para renderização de partículas interativas em tempo real (`#cyber-canvas`).
- **🧭 Navegação Inteligente (Navbar Glassmorphism):** Barra fixa no topo com desfoque de fundo (`backdrop-filter: blur`), navegação suave (*smooth scroll*) e destaque automático de seção ativa via **Bootstrap ScrollSpy**.
- **🎵 Player de Áudio Tecno com Equalizador Animado:** Botão interativo na barra de navegação com barras de equalização animadas via `@keyframes` que reagem ao estado de reprodução.
- **🤖 Avatar SVG 3D Customizado:** Ilustração vetorial exclusiva integrada com anel giratório em gradiente cônico e efeito de inclinação (*tilt*).
- **⌨️ Efeito Typewriter (Máquina de Escrever):** Subtítulo dinâmico com cursor piscante na seção Hero.
- **🖥️ Terminal Python & Laboratório Interativo:** Janela estilizada em formato de console (`Fira Code`) para demonstração de scripts, automações e experimentos.
- **📱 Totalmente Responsivo:** Construído sobre o sistema de grid do **Bootstrap 5.3.3**, adaptando-se a dispositivos móveis, tablets e desktops.

---

## 🗂️ Estrutura das Seções

1. **Início / Perfil (`#perfil`):** Apresentação, badges de status e formação, métricas rápidas (repositórios, formações, foco), links de ação e avatar estilizado.
2. **Formação & Skills (`#formacao`):** Linha do tempo acadêmica (`timeline-cyber`) e barras de progresso com brilho neon (`progress-bar-cyber`) para habilidades técnicas.
3. **Projetos (`#projetos`):** Vitrine de repositórios e sistemas desenvolvidos com suporte a carrossel customizado (`carousel-cyber`).
4. **Laboratório & Vídeo (`#laboratorio`):** Espaço interativo com simulador de terminal Python e demonstrações multimídia.
5. **Contato (`#contato`):** Formulário estilizado com foco neon (`form-control-cyber`) e links diretos para redes profissionais.
